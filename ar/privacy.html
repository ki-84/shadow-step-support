نوضح هنا هذا الموقع التعريفي والتطبيق قيد التطوير كلًّا على حدة.

هذا الموقع التعريفي

يُستضاف الموقع عبر GitHub Pages. لا يضع المشغّل أدوات تحليل زيارات أو إعلانات أو ملفات Cookie للتتبع أو استمارات تسجيل أعضاء. عند الضغط على زر الاستماع، يُحمّل صوت الدرس من GitHub Pages.

تعالج GitHub، مزوّد الاستضافة، معلومات الاتصال وغيرها لتقديم الموقع وحمايته. للتفاصيل، راجع بيان الخصوصية في GitHub.

لا يُستخدم الميكروفون ولا يُسجل صوت أثناء الاستماع التجريبي. عند استخدام «نسخ الرابط»، يُكتب URL هذا الموقع في الحافظة. لا توجد آلية لقراءة محتوى الحافظة.

تواصل معنا

تكون منشورات الدعم على GitHub Issues علنية وتُدار في خدمة GitHub. لا تنشر معلومات شخصية أو تسجيلات صوتية. للتفاصيل، راجع صفحة الدعم.

حول التطبيق قيد التطوير

صُمم التطبيق لحفظ تسجيلات التعلم وسجلها وتحليل النطق داخل الجهاز. لا توجد آلية لإرسال التسجيلات إلى خادم للتحليل. يمكنك حذف تسجيلاتك أو تصدير ملفاتها بنفسك.

نخطط لتمويل النسخة المجانية المبكرة بإعلانات بانر من Google AdMob. تظهر في الرئيسية وقائمة الدروس، ولا تظهر أثناء الدروس أو المراجعة أو في شاشة التقدم. يمكنك التعلم حتى إن تعذر تحميل الإعلانات.

لتقديم الإعلانات ومنع الاحتيال والقياس، تعالج حزم Google للإعلانات وإدارة الموافقة بيانات مثل عنوان IP ومعرّفات الجهاز والمنطقة التقريبية ومرات عرض الإعلانات والتفاعل معها ومعلومات الأعطال والأداء. لا توجد آلية لتمرير التسجيلات أو التفريغ أو محتوى التعلم إلى حزم الإعلانات.

تطلب هذه النسخة إعلانات غير مخصصة، ولا تطلب إذن التتبع للوصول إلى معرّف الإعلانات. تظهر شاشة موافقة Google في المناطق التي تتطلبها. ويمكنك تغيير الاختيار عبر «إعدادات خصوصية الإعلانات» في إعدادات التطبيق. للتفاصيل، راجع استخدام Google للبيانات المتعلقة بالإعلاناتومستندات الإفصاح عن بيانات SDK. التطبيق حاليًا قيد التحضير للإصدار.
