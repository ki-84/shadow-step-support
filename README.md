# シャドステ / ShadowStep

英語学習アプリ「シャドステ」の紹介・サポートサイトです。

**公開サイト：https://ki-84.github.io/shadow-step-support/**

## ページ

- `index.html`：アプリ紹介、教材の試聴、7コース、学び方、FAQ
- `guide.html`：はじめてのシャドーイングと5ステップの学び方
- `support.html`：公開状況、不具合・ご意見の窓口
- `privacy.html`：紹介サイトのプライバシーと開発中アプリの方針

アプリは公開準備中です。月額課金なし・広告で支える先行版を予定しています。このリポジトリにはアプリ本体、認識モデル、利用者の録音、全編の台本は含みません。

## 編集・公開

ビルド不要の静的HTML/CSS/JavaScriptです。GitHub Pagesの配信元は `main` ブランチのルートです。更新を `main` にpushすると再配信されます。

ローカル確認：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

http://127.0.0.1:4173/ を開きます。音声は操作したときだけ再生されます。外部ライブラリ、解析タグ、広告SDK、Webフォントを読み込みません。

公開リンクが確定したら、トップ・FAQ・サポートの「公開準備中」を一緒に更新します。URLを変更した場合は、canonical、OGP、`robots.txt`、`sitemap.xml`、`main.js` の共有URLも変更してください。

## 素材とライセンス

文章・教材抜粋・画像・音声を公開していることは、それらをオープンソース化・再配布許諾するものではありません。第三者による利用は、適用される権利と条件を確認してください。

**Built with Fish Audio**

試聴音声の生成に使ったモデルのライセンス・通知を `assets/FISH_AUDIO_LICENSE.txt` と `assets/FISH_AUDIO_NOTICE.txt` に収録しています。

## 確認した内容

- PC幅、390px・320px幅での表示と横はみ出し
- 1台詞ずつの試聴・前後の切替、日本語訳切替、5ステップ選択、キーボード移動、FAQ開閉
- 音声のデコード、再生・一時停止、同時再生防止（ブラウザの再生確認は無音で実施）
- 内部リンク、アンカー、サイトマップ、JavaScriptの構文

## 多言語ページ

日本語のURLを維持し、英語ほか23言語を言語別ディレクトリで提供します。全24言語でホーム、学び方、サポート、プライバシーの4ページを用意しています。言語切替は同じ種類のページへ移動し、自動リダイレクトは行いません。音声・画像は全言語で共有します。

翻訳はAIによる制作と原文照合です。アプリの24言語版は準備中で、公開後にダウンロード案内を更新します。
