رازداری کے بارے میں

اس تعارفی سائٹ اور زیرِ تیاری ایپ کی معلومات الگ بتاتے ہیں۔

یہ تعارفی ویب سائٹ

سائٹ GitHub Pages پر ہے۔ منتظم کی جانب سے تجزیاتی ٹریکنگ، اشتہارات، ٹریکنگ کوکی یا رجسٹریشن فارم نہیں۔ نمونہ دبائیں تو GitHub Pages سے تعلیمی آڈیو آتی ہے۔

ہوسٹنگ فراہم کرنے والا GitHub سائٹ پہنچانے اور حفاظت کے لیے کنکشن کی معلومات وغیرہ استعمال کرتا ہے۔ مزید تفصیل کے لیےGitHub کا رازداری بیانملاحظہ کریں۔

نمونہ سنتے وقت مائیکروفون یا ریکارڈنگ استعمال نہیں۔ «لنک کاپی کریں» دبانے پر صرف سائٹ کا URL کلپ بورڈ میں لکھا جاتا ہے۔ کلپ بورڈ پڑھنے کا عمل نہیں۔

رابطہ کریں

معاونت کے GitHub Issues میں پوسٹ سب کو نظر آتی ہے، GitHub پر سنبھالی جاتی ہے۔ ذاتی معلومات یا آواز پوسٹ نہ کریں۔ مزید تفصیل کے لیےمعاونت کا صفحہملاحظہ کریں۔

زیرِ تیاری ایپ کے بارے میں

تعلیمی آواز اور تاریخ ڈیوائس میں محفوظ، تلفظ کا تجزیہ بھی وہیں ہوتا ہے۔ تجزیے کے لیے سرور کو آواز بھیجنے کا نظام نہیں۔ آپ آواز حذف یا فائل ایکسپورٹ کر سکتے ہیں۔

ابتدائی مفت نسخہ Google AdMob بینر اشتہارات سے چلانے کا منصوبہ ہے۔ ہوم اور مواد کی فہرست پر، سبق، دہرائی اور پیش رفت پر نہیں۔ اشتہار نہ ملے تب بھی پڑھ سکتے ہیں۔

اشتہارات، دھوکا روکنے اور پیمائش کے لیے Google کے اشتہاری و رضامندی SDK، IP پتہ، ڈیوائس شناخت، عمومی علاقہ، اشتہار دیکھنے و استعمال اور خرابی و عمل کی معلومات لیتے ہیں۔ آواز، لکھا متن یا سیکھا مواد اشتہاری SDK کو نہیں دیتے۔

یہ نسخہ غیر شخصی اشتہارات مانگتا ہے، اشتہاری ID تک رسائی کی ٹریکنگ اجازت نہیں۔ ضروری علاقوں میں Google کی رضامندی اسکرین ہو گی؛ ایپ ترتیبات کی «اشتہارات کی رازداری کی ترتیبات» سے پسند بدلیں۔ مزید تفصیل کے لیےاشتہارات کے لیے Google کا ڈیٹا استعمالاورSDK کے ڈیٹا کے افشا کی دستاویزاتملاحظہ کریں۔ ایپ فی الحال اجرا کی تیاری میں ہے۔
