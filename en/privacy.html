PRIVACY

Privacy

This website and the app in development are explained separately.

This Website

This site is hosted on GitHub Pages. The operator has not added analytics, ads, tracking cookies, or a registration form. Pressing a preview button loads a lesson audio file from GitHub Pages.

The hosting provider, GitHub, handles connection information and other data to deliver and secure the website. For details, see the GitHub Privacy Statement.

Previewing does not access the microphone or record audio. When you press “Copy link,” this site’s URL is written to the clipboard. Nothing reads the clipboard’s contents.

Contact

Posts to the support channel on GitHub Issues are public and managed on GitHub’s service. Do not post personal information or recordings. For details, see the Support Page.

About the App in Development

Learning recordings and history are saved on your device, and pronunciation analysis is designed to run on the device too. There is no system for sending recordings to a server for analysis. You can delete your recordings or export files yourself.

The early free version is planned to be supported by Google AdMob banner ads. They will appear on Home and the lesson list, but not during lessons, reviews, or on the progress screen. You can still study when ads cannot be loaded.

To deliver ads, prevent fraud, and measure performance, Google’s advertising and consent SDKs handle data such as IP addresses, device identifiers, approximate location, ad impressions and interactions, and crash and performance information. No process is provided to pass recordings, transcripts, or lesson learning content to the advertising SDKs.

This version requests non-personalized ads and does not request tracking permission for access to the advertising ID. Google’s consent screen is shown where required, and you can change your choices through “Ad privacy settings” in the app’s Settings. For details, see Google’s Use of Data for Advertising and SDK Data Disclosures. The app is currently being prepared for release.

Changes and questions
