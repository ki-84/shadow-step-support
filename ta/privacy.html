தனியுரிமை பற்றி

இந்த அறிமுகத் தளத்தையும் உருவாகும் செயலியையும் தனித்தனியாக விளக்குகிறோம்.

இந்த அறிமுக இணையதளம்

இந்தத் தளம் GitHub Pagesஇல் இயங்குகிறது. நடத்துநர் வைத்த பார்வை ஆய்வு, விளம்பரம், கண்காணிப்புக் குக்கீ, உறுப்பினர் படிவம் இல்லை. மாதிரிப் பொத்தானை அழுத்தினால் GitHub Pagesஇலிருந்து பாட ஒலி வரும்.

தள விநியோகம், பாதுகாப்புக்காக இணைப்புத் தகவல் உள்ளிட்ட தரவை வழங்குநர் GitHub கையாள்கிறது. மேலும் விவரங்களுக்கு: GitHub தனியுரிமை அறிக்கை.

மாதிரி கேட்கும்போது மைக்ரோஃபோன் அணுகலோ பதிவோ இல்லை. “இணைப்பை நகலெடு” அழுத்தும்போது தள URLஐ கிளிப்போர்டில் எழுதும். கிளிப்போர்டைப் படிக்காது.

தொடர்புகொள்ள

உதவிக்கான GitHub Issues பதிவுகள் பொதுவில் தெரிந்து GitHubஇல் நிர்வகிக்கப்படும். தனிப்பட்ட தகவல் அல்லது குரலைப் பதிவிடாதீர்கள். மேலும் விவரங்களுக்கு: உதவிப் பக்கம்.

உருவாக்கத்தில் உள்ள செயலி பற்றி

கற்றல் பதிவும் வரலாறும் சாதனத்தில் சேமித்து உச்சரிப்பு ஆய்வையும் அங்கேயே செய்ய வடிவமைக்கப்பட்டுள்ளது. ஆய்வுக்காக ஒலியைச் சேவையகத்துக்கு அனுப்பும் முறை இல்லை. பதிவை நீக்கவும் ஏற்றுமதி செய்யவும் முடியும்.

ஆரம்ப இலவசப் பதிப்பை Google AdMob பேனர் விளம்பரங்களால் இயக்கத் திட்டம். முகப்பு, பட்டியலில் மட்டும்; பாடம், மீள்பயிற்சி, முன்னேற்றத்தில் இல்லை. விளம்பரம் கிடைக்காவிட்டாலும் கற்கலாம்.

விளம்பர விநியோகம், மோசடி தடுப்பு, அளவீட்டுக்கு Google விளம்பர, ஒப்புதல் SDKகள் IP முகவரி, சாதன அடையாளம், தோராயப் பகுதி, விளம்பரக் காட்சி, செயல்பாடு, பிழைத் தகவல் போன்றவற்றைக் கையாளும். ஒலி, எழுத்துப் பதிவு, கற்றல் உள்ளடக்கத்தை விளம்பர SDKக்கு அனுப்பும் முறை இல்லை.

இந்தப் பதிப்பு தனிப்பயனாக்காத விளம்பரம் கேட்கும்; விளம்பர IDக்கான கண்காணிப்பு அனுமதி கேட்காது. தேவையான பகுதிகளில் Google ஒப்புதல் திரை வரும். அமைப்பிலுள்ள “விளம்பரத் தனியுரிமை அமைப்புகள்” மூலம் தேர்வை மாற்றலாம். மேலும் விவரங்களுக்கு: Google விளம்பரத் தரவுப் பயன்பாடு மற்றும் SDK தரவு வெளிப்படுத்தல் ஆவணங்கள். செயலி தற்போது வெளியீட்டுக்குத் தயாராகிறது.

மாற்றங்கள் மற்றும் கேள்விகள்

தகவல் மாறினால் இந்தப் பக்கத்தின் புதுப்பித்த தேதியும் மாற்றப்படும். கேள்விகள் இருந்தால் தொடர்புகொள்ளுங்கள்: உதவி மையம்.
